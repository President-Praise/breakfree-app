# BreakFree

A mobile app that helps people quit compulsive behaviors — social media addiction, gambling, porn, and more.

Built with Expo and React Native, backed by Supabase.

## Features

- **Habit tracking** — choose the behavior you want to quit, track your streak
- **Daily check-ins** — log progress or relapses honestly
- **Streak dashboard** — visualize your progress over time
- **Auth** — sign up / login via Supabase
- **Dark mode** — clean, minimal UI designed for focus

## Tech stack

- **React Native + Expo** — cross-platform mobile (iOS & Android)
- **Expo Router** — file-based navigation
- **Supabase** — auth, database, storage
- **TypeScript** — end to end

## Getting started

```bash
cp .env.example .env   # add Supabase credentials
npm install
npx expo start
```
